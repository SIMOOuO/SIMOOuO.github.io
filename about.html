Who am I? | 我是谁？

I'm an IT student passionate about web development and technology. This website started as a personal project to keep track of useful websites and tools I discover during my learning journey.

我是一名热爱网页开发和技术的IT学生。这个网站最初是一个个人项目，用来记录我在学习过程中发现的有用网站和工具。

Over time, it grew into a curated collection covering everything from productivity tools and study resources to games and creative tools. I believe in sharing knowledge — if a website helped me, it might help someone else too.

随着时间推移，它发展成了一个精选合集，涵盖从生产力工具、学习资源到游戏和创意工具的方方面面。我相信分享知识——如果一个网站帮助了我，它也可能帮助到别人。

What's on this site? | 网站上有什么？

Home | 首页 — A curated list of 60+ useful websites organized by category: Tools, Study, Games, and Other. Each entry includes a short description of why I find it useful.

精选的60+个有用网站列表，按类别分类：工具、学习、游戏和其他。每个条目都附有简短描述。

Tools | 工具页 — API-powered tools including book search (Open Library), currency converter (ExchangeRate API), Pokémon lookup with stat bars (PokéAPI), and country info with map links (countries.dev).

API驱动的工具，包括图书搜索（Open Library）、货币转换器（ExchangeRate API）、带属性条的宝可梦查询（PokéAPI）和带地图链接的国家信息（countries.dev）。

Recipe Finder | 食谱搜索 — A fun tool that lets you search for recipes by ingredient or cuisine, powered by TheMealDB API.

一个有趣的工具，让你按食材或菜系搜索食谱，由TheMealDB API提供支持。

Anime | 动漫页 — Anime search and discovery with seasonal charts, top rated lists, and detailed info modals (powered by AniList API).

动漫搜索与发现，包含季度图表、最高评分列表和详细信息弹窗（由 AniList API 提供支持）。

Games | 游戏页 — Gaming highlights and clips from my favorite sessions.

我最喜欢的游戏精彩片段和录像。
