Who am I?

I'm an IT student passionate about web development and technology. This website started as a personal project to keep track of useful websites and tools I discover during my learning journey.

Over time, it grew into a curated collection covering everything from productivity tools and study resources to games and creative tools. I believe in sharing knowledge — if a website helped me, it might help someone else too.

What's on this site?

Home — A curated list of 60+ useful websites organized by category: Tools, Study, Games, and Other. Each entry includes a short description of why I find it useful.

Recipe Finder — A fun tool that lets you search for recipes by ingredient or cuisine, powered by TheMealDB API.

Games — Gaming highlights and clips from my favorite sessions.

Tech Stack

This site is built with pure HTML, CSS, and JavaScript — no frameworks, no build tools. It's hosted on GitHub Pages for free.
